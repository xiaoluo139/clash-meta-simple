Clash Simple for Windows —— 使用说明（重要，先看这个）
==================================================

一、双击 ClashSimple.exe 弹出「智能应用控制已阻止可能不安全的应用」
----------------------------------------------------------------
消息内容是"因为无法验证其发布者，无法确认它是否能安全运行"。

原因：这是 Windows 11 的「智能应用控制（Smart App Control）」在拦截**未签名程序**。
它只允许「有可信签名」或「已有良好信誉」的程序运行。
ClashSimple.exe 是没买代码签名证书的小工具，系统无法验证发布者，所以直接拦下
——这跟你的电脑安全与否、跟程序本身是否安全都无关，
任何未签名的新程序都会遇到同样的拦截。

注意：右键属性里勾"解除锁定"对这种情况**无效**（那是针对"文件被锁定"的）。


二、解决办法（任选其一）
------------------------

★ 方案一（推荐）：用脚本版，界面和功能完全一样
  1. 先「解除锁定」：右键这个 zip → 属性 → 最下面勾选"解除锁定" → 确定
     （没有"解除锁定"这一项就跳过）
  2. 解压
  3. 双击   Start.bat
  4. 会打开一个 "Clash Simple" 窗口（用 Edge 应用模式显示，看起来就是独立程序）

  用法与 exe 版完全一致：大圆环=总开关，三张卡=模式选择，
  节点可测速 / 自动选择最快 / 点击切换，右上角有 IP 检测。

方案二：关闭「智能应用控制」
  设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制
      → 智能应用控制 → 关闭

  !! 重要 !! 「智能应用控制」一旦关闭，除非重装 Windows，否则无法再开启。
  （这是微软的设计）如果你不想关，请用方案一。

方案三：换一台没开「智能应用控制」的电脑
  Windows 11 全新安装默认开启该功能；从 Windows 10 升级上来的一般没开，
  那种机器可以直接双击 ClashSimple.exe。


三、如果脚本版提示「内核启动失败」
----------------------------------
说明内核 mihomo.exe 也被系统拦住了（同样是未签名程序）。

1. 请先确认按方案一里说的，**先给 zip 解除锁定再解压**（这一步很关键，
   通过微信/浏览器下载的文件会被打上"来自互联网"标记，系统会更严格地拦它）
2. 如果解除锁定后仍失败，就只能用方案二（关闭智能应用控制）


四、目录说明
------------
ClashSimple.exe        主程序（系统允许未签名程序时可用）
Start.bat              脚本版启动器 ← 被拦截时用这个
SimpleClash.ps1        脚本版主程序
ui.html                脚本版界面
Run-Native.ps1         另一种启动方式（把程序以库的形式载入，部分机器可用）
core\mihomo.exe        内核 v1.19.31
data\                  运行时生成：订阅、配置、日志


五、使用步骤（两种版本都一样）
------------------------------
1. 打开程序 → 「订阅」里粘贴你的 Clash 订阅链接 → 保存并应用
2. 点大圆环启动代理（会自动设置 Windows 系统代理）
3. 需要时点「自动选择最快」（只选测通的节点，不会选到超时节点）
4. 关闭程序即停止代理并还原系统代理


六、常见问题
------------
Q: 提示"没有测通的节点"？
A: 当前节点组里所有节点都连不上。确认订阅有效、网络正常，或换个节点组再试。

Q: 提示"无法建立安全连接（SSL/TLS）"？
A: 已修复（程序启动时会显式开启 TLS 1.2）。若仍失败，先检查系统时间是否正确。

Q: 内核启动失败，日志里写 "mapping key already defined"？
A: 已修复（生成配置时会把订阅里重复的端口/log-level 等字段剔除）。

Q: 杀毒软件报警？
A: 未签名小工具常见误报。可自行核对 mihomo 官方校验值。

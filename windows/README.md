# Clash Simple for Windows

基于 **mihomo** 内核的极简 Windows 客户端，与 Android 端 *Clash Simple* 配套。
界面沿用了手机版的交互：**大圆环 = 总开关，下面两张卡 = 模式选择**。

![界面示意](#)

## ✨ 功能

| 功能 | 说明 |
| --- | --- |
| 一键开关 | 点大圆环启动 / 停止；启动时**自动设置 Windows 系统代理**，停止时自动还原 |
| 分流模式 | 规则 / 全局 / 直连 三选一，点击即切换（不会误触发启动） |
| 节点测速 | 一键对当前节点组测速，列表显示每个节点延迟并着色 |
| **自动选择最快** | 只挑「**测通**」的节点（mihomo 的测速接口只返回成功节点），选其中延迟最低的 |
| 手动选节点 | 点击任意节点即可切换，当前节点高亮 + 勾选 |
| 订阅 | 粘贴订阅链接保存；随时「更新订阅」拉取最新节点 |
| **IP 检测** | 右上角一键打开 <https://ip.skk.moe/> |
| 多节点组 | 自动识别 Selector / URLTest / Fallback 等分组 |

## 🚀 使用

1. 解压后双击 **`Start.bat`**
2. 首次运行会自动下载 mihomo 内核（约 20 MB，需联网）；如果压缩包里已带 `core/mihomo.exe` 则直接使用
3. 在「订阅」里粘贴你的 Clash 订阅链接 → **保存并应用**
4. 点大圆环启动 → 需要时点「自动选择最快」
5. 关闭窗口即停止代理并还原系统代理

> 默认混合代理端口 `7890`，控制端口 `9090`（仅监听 127.0.0.1）。
> 可在 `SimpleClash.ps1` 顶部的参数里修改。

## 📁 目录结构

```
windows/
├── Start.bat          双击启动
├── SimpleClash.ps1    主程序（HTTP 服务 + 内核管理 + 系统代理）
├── ui.html            界面
├── core/              mihomo.exe（首次自动下载）
└── data/              运行时生成：订阅原文、config.yaml、设置、日志
```

## ⚙️ 工作原理

- 内核就是 **mihomo**（与 Android 端同一内核），监听 `127.0.0.1:9090` 的 RESTful API
- 订阅原文保存在 `data/profile.yaml`；程序生成 `data/config.yaml` 时会**剔除订阅里自带的端口/控制器字段**，
  再写入自己的 `mixed-port` / `external-controller`，避免 YAML 重复键报错
- 界面由本地 HTTP 服务（仅 127.0.0.1）提供，默认用 **Edge 的应用窗口模式**打开，看起来就是一个独立程序
- 「自动选择最快」调用 `/group/{name}/delay`，该接口**只返回测通的节点**，因此不会选到超时节点

## ❓ 常见问题

**Q：提示"没有测通的节点"？**
A：说明当前节点组里所有节点都连不上。先确认订阅有效、网络可用，或换个节点组再试。

**Q：浏览器 / 某些程序不走代理？**
A：只设置了系统代理（WinINET）。部分程序（如某些游戏、CLI 工具）需要单独配置代理，或用 TUN 模式。

**Q：想用 TUN（全局虚拟网卡）模式？**
A：Windows 端需要管理员权限并额外配置，当前版本未内置；可自行修改 `data/config.yaml` 的 `tun` 段。

**Q：杀毒软件报警？**
A：脚本 + 自行下载的内核，属正常误报。可以自行核对 mihomo 官方校验值。
